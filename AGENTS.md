# Agent Instructions

This is a public reusable package repository. Do not add personal data, private evidence files, private reporting records, or generated personal CV/site outputs here.

## Boundaries

- Keep generic academic-profile logic here.
- Keep personal data in private site repositories.
- Keep Quarto theme and presentation code in theme repositories.
- Icelandic public-university reporting support may live here as a plugin/module, but it must be generic and source-cited.

## Workflow

- Work on branches.
- Do not push feature work directly to `main`.
- Use pull requests and squash merge.
- Delete branches after merge.
- Tag releases for usable package versions.
- Keep changes small and reviewable.
- Add tests for parsing, validation, filtering, and reporting logic.
