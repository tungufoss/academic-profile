# academic-profile

Reusable academic profile data pipeline for publications, CVs, projects, activities, evidence, and reporting.

This is a public, generic package repository. It must not contain personal academic data from `tungufoss.github.io`.

## Scope

- Publication parsing and filtering
- CV selection and generation helpers
- Project and activity data models
- Evidence tracking
- Reporting scheme support, including plugin-style support for Icelandic public-university reporting schemes

## Repository Rules

- Work on branches, not directly on `main` after initial setup.
- Use pull requests and squash merge.
- Tag releases when publishing usable versions.
- Keep theme/presentation code out of this package.
- Keep personal/private data out of this public repository.
